# Image Source Aggregator iOS Prototype

SwiftUI layout prototype for an iPhone app that aggregates image sources and lets users add custom sources.

The prototype focuses on native iOS 26 structure and interactions:

- Tab Bar with Home, Search, Sources, and Settings.
- NavigationStack for secondary pages.
- Lists and Forms for source management.
- Sheets for adding sources and search filtering.
- Grid, detail, and full-screen browsing flows.
- Native toolbar and Liquid Glass button styles where appropriate.

CI builds an unsigned IPA through GitHub Actions on macOS using XcodeGen.
